## 🚀 Como Rodar Localmente

### Pré-requisitos
- Node.js 18+ (Node 20 ou 22 recomendado)

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor local
npm run dev

# 3. Gerar build de produção
npm run build
```

## ☁️ Instruções Simples para Deploy na Vercel

1. Acesse [vercel.com](https://vercel.com) e conecte com sua conta do GitHub.
2. Clique em **Add New...** > **Project**.
3. Selecione o repositório **`matheus-araujo-pereira/curriculo-online`** e clique em **Import**.
4. A Vercel detectará automaticamente o preset **Vite** e configurará:
   - **Framework:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Clique em **Deploy**. O site estará no ar em poucos segundos com certificado SSL gratuito e deploy contínuo em cada `git push` na branch `main`.
